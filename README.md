## 七、近期关键修复（2026-10-12）

**解决了"没有网络 / 推流断了 / 打开摄像头时程序卡死"的问题：**

- 新增统一取流内核 `camera_stream.py`（01/02/03 各一份独立副本）：
  - `cv2.VideoCapture` / `cap.read()` 改为**后台线程 + 超时**，界面线程永不阻塞；
  - 增加**看门狗**：连续无新帧超过阈值就判"画面中断"，自动重连，不 join 卡死的线程；
  - `cap.release()` 走后台线程，避免释放时把界面一起拖死；
  - FFMPEG 网络流附加 socket 超时、keepalive、低延迟选项，让 read() 尽量自己返回；
  - 限制并发探测与重连，避免网络一直不通时线程无限堆积。
- 重写 `02 gui.py` / `03 terminal_gui.py` 的监控播放逻辑：
  - 点"播放"立刻显示"正在连接…"，后台异步打开；
  - "画面中断"状态橙字提示，自动重连；打开失败显示具体原因；
  - 停止/关闭窗口时立即返回，不等待卡住的网络线程。
- 修复 `01 video.py` / `capture.py` / `gui.py`：
  - 实时视频开启改为后台线程，不再冻住界面；
  - 抓拍增加整体超时，超时有帧用帧，无帧才报错。
- 修复 `00 集成联动/linkage.py`：
  - 子进程调用超时后**强制终止整个进程树**，避免孙进程（ollama / 取流）占着管道导致假死；
  - 默认超时从 180 秒降到 60 秒，并可由调用方配置。
- 网页端 `fetch` 增加超时（02 网页核查面板 / 01 网页操作面板），防止后端卡顿时浏览器一直转圈。
- 新增 13 项取流防卡死单元测试，02 全量 110 项、01 全量 186 项、03 全量 121 项、02 端到端自检 108 项、00 集成联动自检 23 项均通过。

## 八、AI 算法 · UI · 数据加密优化（2026-10-13）

### 8.1 AI 算法：面向 40 人同框大教室

`person_detect.py`（02/03 各一份，内容完全一致）重写为**多源密集检测**：

| 能力 | 说明 |
| --- | --- |
| DNN 优先 | 目录下存在 `MobileNetSSD_deploy.prototxt` + `.caffemodel` 时用 `cv2.dnn` 检测行人；无模型自动回退 HOG 并只提示一次 |
| HOG 密集模式 | `winStride=(4,4)`、`padding=(16,16)`、`scale=1.03` + 自适应阈值 + 软 NMS，显著提升密集召回 |
| 背景差分辅助 | `MOG2` 补充静止/密集人群 ROI |
| Haar 人头辅助 | 画面上半部用 frontalface 级联找人并推断人身框，补 HOG 漏检的坐姿考生 |
| 更小的框 | 默认 `margin_ratio=0.02`（2% 边距），最小 24×24；框线 1px、标签 13px、只在必要时显示跨线次数 |
| 性能 | `max_input_dim=640` 缩放检测、`detect_stride` 跳帧 + 匀速预测、匈牙利匹配（scipy 可选） |
| 密度感知 | `density_level` = low/medium/high，高密度自动切换密集参数 |
| 生命周期 | 新增 `stop()` / `start()`，可清空轨迹并复位计数器 |

### 8.3 考生数据加密存储

新增 `data_crypto.py`（01/02/03 各一份，内容完全一致），基于 **Fernet（AES-128-CBC + HMAC-SHA256）** 做字段级加密：

- 密钥来源：环境变量 `EXAM_DATA_KEY` 优先，否则读/生成 `data/.data_key`（`data/` 已在 `.gitignore` 中，密钥不入库）；
- 加密字段带 `enc:` 前缀，可识别密文并**兼容历史明文**（读取时明文原样返回，写入时自动加密）；
- `install_env.py` 已加入 `cryptography` 依赖。

| 项目 | 加密字段 |
| --- | --- |
| 01 人脸识别 | 考生 `name` / `ticket_no` / `seat_no` / `reference_photo`（身份证仍为 salt+hash+掩码，不落明文）；参考照文件经 `face_engine.imwrite_unicode(encrypt=True)` 加密落盘，`imread_unicode` 透明解密 |
| 02 摄像头核查 | `devices.name`、`devices.position`；`workorders.note`、`workorders.review_note` |
| 03 智能终端 | `alerts.candidate_id` / `candidate_name` / `seat_no` / `detail`；`reviews.reason` / `attachments` |

> 注意：密钥与数据库同机存放，属于"静态加密 + 访问控制"级别；生产环境建议把 `EXAM_DATA_KEY` 托管到 KMS/密钥管理系统，并定期轮换。
> 加密后**丢失密钥即无法恢复数据**，请务必先备份 `data/.data_key`。
