## 二、两条最能说明问题的实测结论

**① 40 人考场：单张推理会把分辨率白白丢掉，必须分块。**

| 配置 | 召回（合成 40 人考场，真实人物素材） | 精确 | 单路分析耗时 |
| --- | --- | --- | --- |
| 640 单张（原默认） | 12.5% | 71% | 27 ms |
| 1280 / 1920 单张 | 22.5% / 25% | 90% | 27 ms |
| **1280 + 分块 auto（现密集档默认）** | **62.5%** | **89%** | 约 190 ms |

**② 逐帧标签会被瞬时动作骗，作弊识别用时序把误报压掉。**

| 场景 | 结果 |
| --- | --- |
| 安静答题 6 秒 | 正常，不告警 |
| 伸懒腰 / 单帧大幅偏转（瞬时） | 风险 1.1，**不告警**（时间维度抑制） |
| 持续侧头看邻座 + 多模态判出手机 | 第 5 帧起红色预警（风险 85.9→100），**告警** |

## 三、如实说明

- 上面 40 人场景是**合成画面**（人物外观取自真实抓拍，排布为合成），只用于**横向比较配置**，
  **不等于真实考场准确率**；真实指标必须用考场现场样本。
- 摄像机路径下，作弊识别引擎自己声明 **手部交互 / 违禁物体 / 表情 = 不可得**（无骨骼点与物体模型），
  结合层原样透出；物体类证据来自**多模态大模型判读**（VLM 开启才有），单靠 YOLO 认不出手机。
- `yolo11n.onnx` 等模型不入库（见 `.gitignore`），各子方案用 `下载模型.py` / `工具_YOLO模型导出.py` 获取。
