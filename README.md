## 二、七个项目一览

| 项目 | 名称 | 核心内容 | 关键结论 |
| --- | --- | --- | --- |
| 项目一 | 方案定位与技术架构 | 定位、目标、端-边-云三层协同、设备与网络配置 | 闭环管理：AI 识别 → 告警推送 → 人工复核 → 现场处置 → 数据追溯 |
| 项目二 | 实施与部署 | 四阶段路线图、试点验证、硬件选型与预算 | 60-90 天周期；签约后 45 天完成建设 + 1 个月试运行 |
| 项目三 | 合规与数据治理 | 法律依据、采集/处理/存储/使用四层合规措施、数据安全架构 | 单独同意、最小必要、30 天保留、可解释输出 |
| 项目四 | 验收与运维 | 验收指标、第三方检测、3 年质保、巡检与算法迭代 | 准确率 ≥ 95%、告警 ≤ 3 秒、可用性 ≥ 99% |
| 项目五 | 风险与保障 | 风险管控、供应商选择、关键成功要素 | 利旧、试点、人机协同、合规前置、持续迭代 |
| 项目六 | 智能化装备与考生数据保护 | 人脸识别、摄像头核查、智能终端、巡考机器人、考生数据保护（自主补充 4 个专题）+ **专题 10 普通考场+特殊考场应用** | 事前阻断 + 事中核验 + 事后发现 + 全程保护 + 场景落地；详见 [项目六 README](项目六_智能化装备与考生数据保护/README.md) |
| 项目七 | 教学场景应用 | 非考试期的 **AI 教师巡视教室**：到课统计、课堂秩序提示、教学行为观察、课堂互动、录播与巡课报告 | **考试模式管考场，教学模式管课堂**；教学场景禁止学生个体评价、排名与成绩挂钩；详见 [项目七 README](项目七_教学场景应用/README.md) |
