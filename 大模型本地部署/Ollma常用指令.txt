========================================
Ollama 常用指令大全
========================================

【一、模型管理】

1. 下载/拉取模型
   ollama pull <模型名>
   示例：ollama pull llama3
         ollama pull qwen2.5
         ollama pull deepseek-r1

2. 运行模型（进入对话）
   ollama run <模型名>
   示例：ollama run llama3
   退出对话：/bye  或 Ctrl+D

3. 列出本地已有模型
   ollama list

4. 查看模型详细信息
   ollama show <模型名>
   示例：ollama show llama3
   可选参数：
     ollama show --modelfile <模型名>   查看 Modelfile
     ollama show --parameters <模型名>  查看参数
     ollama show --template <模型名>    查看模板
     ollama show --system <模型名>      查看系统提示

5. 删除本地模型
   ollama rm <模型名>
   示例：ollama rm llama3

6. 复制/重命名模型
   ollama cp <源模型> <新模型名>
   示例：ollama cp llama3 my-llama3

7. 从 Modelfile 创建自定义模型
   ollama create <模型名> -f <Modelfile路径>
   示例：ollama create mymodel -f ./Modelfile

8. 推送模型到 Ollama 仓库
   ollama push <用户名>/<模型名>

9. 更新本地已有模型
   ollama pull <模型名>   （重新拉取即为更新）


【二、服务与运行】

10. 启动 Ollama 服务
    ollama serve

11. 查看正在运行的模型
    ollama ps

12. 停止正在运行的模型
    ollama stop <模型名>
    示例：ollama stop llama3

13. 查看版本
    ollama --version
    ollama -v

14. 查看帮助
    ollama --help
    ollama -h
    ollama <子命令> --help


【三、对话中的内置指令（在 ollama run 后输入）】

15. /bye          退出对话
16. /?  或 /help  查看对话内帮助
17. /set          查看/设置会话参数
18. /show         查看当前模型信息
19. /load <模型>  加载指定模型
20. /save <模型>  保存当前会话为模型
21. /clear        清空对话上下文
22. /reset        重置会话
23. /exit         退出


【四、常用环境变量】

OLLAMA_HOST         服务监听地址，默认 127.0.0.1:11434
OLLAMA_MODELS       模型存放路径
OLLAMA_KEEP_ALIVE   模型在内存中保持时间，如 5m、1h、-1（永久）
OLLAMA_NUM_PARALLEL 并行请求数
OLLAMA_MAX_LOADED_MODELS  同时加载的模型数量
OLLAMA_DEBUG        开启调试日志（OLLAMA_DEBUG=1）
OLLAMA_FLASH_ATTENTION    开启 Flash Attention（=1）
OLLAMA_KV_CACHE_TYPE      KV Cache 类型，如 q8_0、f16
OLLAMA_GPU_OVERHEAD      预留显存
OLLAMA_NOPRUNE           禁止启动时清理

Linux/macOS 设置示例：
  export OLLAMA_HOST=0.0.0.0:11434
  export OLLAMA_KEEP_ALIVE=30m

Windows (PowerShell) 设置示例：
  $env:OLLAMA_HOST="0.0.0.0:11434"
  $env:OLLAMA_KEEP_ALIVE="30m"


【五、API 调用（默认端口 11434）】

24. 生成补全
    POST http://localhost:11434/api/generate
    {
      "model": "llama3",
      "prompt": "你好",
      "stream": false
    }

25. 对话接口
    POST http://localhost:11434/api/chat
    {
      "model": "llama3",
      "messages": [
        {"role": "user", "content": "你好"}
      ],
      "stream": false
    }

26. 列出本地模型
    GET http://localhost:11434/api/tags

27. 查看模型信息
    POST http://localhost:11434/api/show
    {"name": "llama3"}

28. 拉取模型
    POST http://localhost:11434/api/pull
    {"name": "llama3"}

29. 删除模型
    DELETE http://localhost:11434/api/delete
    {"name": "llama3"}

30. 生成向量嵌入
    POST http://localhost:11434/api/embed
    {"model": "nomic-embed-text", "input": "文本内容"}

31. OpenAI 兼容接口
    POST http://localhost:11434/v1/chat/completions
    POST http://localhost:11434/v1/completions
    POST http://localhost:11434/v1/embeddings
    GET  http://localhost:11434/v1/models

curl 示例：
  curl http://localhost:11434/api/generate -d '{
    "model": "llama3",
    "prompt": "你好",
    "stream": false
  }'


【六、Modelfile 常用参数】

FROM <基础模型>              指定基础模型
PARAMETER temperature 0.7    温度
PARAMETER top_p 0.9          top_p
PARAMETER top_k 40           top_k
PARAMETER num_ctx 4096       上下文长度
PARAMETER repeat_penalty 1.1 重复惩罚
PARAMETER stop "###"         停止词
SYSTEM """系统提示内容"""     系统提示
TEMPLATE """模板内容"""       对话模板
ADAPTER <路径>               LoRA 适配器
LICENSE """许可证"""          许可证

示例 Modelfile：
  FROM llama3
  PARAMETER temperature 0.6
  PARAMETER num_ctx 8192
  SYSTEM """你是一个专业的中文助手。"""

【八、快捷技巧】

- 管道输入：
  echo "你好" | ollama run llama3

- 单次提问不进入交互：
  ollama run llama3 "介绍一下杭州"

- 查看日志（Linux）：
  journalctl -u ollama -f

- macOS 日志：
  cat ~/.ollama/logs/server.log

- 修改模型存储路径：
  export OLLAMA_MODELS=/your/path

- 让模型常驻内存：
  export OLLAMA_KEEP_ALIVE=-1
