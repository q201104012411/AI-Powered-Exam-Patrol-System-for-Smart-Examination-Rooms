# 加密安装包（AES-256-GCM + 自选安装路径）

本目录生成：

```
智能考场AI巡考系统_安装包.exe
```

双击后先弹出“选择安装目录”，确认后：

1. 用“内置混淆密钥材料 + 随机 salt + 安装器自身头部 SHA256”派生 AES-256 密钥；
2. 按 1 MB 分块解密 `payload.enc`（每块 GCM 校验，篡改/密钥不匹配会立即失败）；
3. 解压到 `<安装目录>\app`，保留已有 `data` 等运行数据；
4. 生成 `启动智能考场.lnk`、`启动智能考场.bat`，完成后可直接启动总控台。

安装后的程序运行不经过解密层，启动/运行速度与原来的单文件版一致。

## 构建

前置：已运行 `../一键打包.sh` 生成 `../_build/payload.zip`；Git Bash、Go 1.20+、Python + cryptography。

```bash
cd "exe打包文件/加密打包exe文件"
bash build_installer.sh
```

脚本会：

- 用 `_build/app.ico` 给安装器嵌入图标；
- 随机生成 32 字节密钥材料，只以异或后的形式注入 Go stub；
- 加密 `payload.zip`；
- 追加 `payload.enc` + 40 字节尾部索引（`ZKINS002`）；
- 输出安装包并打印 SHA256。

## 命令行（自动化/测试）

```bat
智能考场AI巡考系统_安装包.exe --dir "D:\Programs\智能考场" --yes --silent --no-launch
```

- `--dir`：直接指定安装目录（不弹选择框）
- `--yes`：跳过确认框
- `--silent`：跳过完成提示
- `--no-launch`：安装后不启动

普通用户双击不带参数，仍走图形选择目录 + 确认框。

## 安全边界（如实说明）

- 安装包内的 payload 全程是密文；直接解压安装包看不到源码/运行时。
- 安装器带 `IsDebuggerPresent` 检查；对安装包做篡改会触发 GCM 校验失败。
- 安装完成后，`app` 下是正常运行所需的 Python 运行时与源码文件；本机有权限的人仍可读取。
  这是“提高提取/逆向门槛”，不是不可破解的 DRM；如需更强保护，需结合代码签名、授权服务器、
  原生编译（Nuitka/Cython）或商业加壳方案。
- 密钥材料在安装器内经过混淆，但逆向者理论上仍可从二进制中还原；不要把“加密”宣传为绝对安全。
