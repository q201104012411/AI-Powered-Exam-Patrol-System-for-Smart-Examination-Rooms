# 2026-10-19 · 单文件总控台（结构目录 + 账户登录）

> 范围：`exe打包文件`。把 00~13 全部子系统、独立 Python 运行时与启动器打成一个
> **单文件 exe**；界面是结构目录，双击模块后要输入账户 + 口令，校验通过才启动。

> 已在只含该 runtime 的目录里跑通 `tkinter/cv2/onnxruntime` 与总控台。

## 1. 界面：结构目录 + 账户登录

- 左侧 `ttk.Treeview` 按 **考场业务系统 / 安全与保障 / AI 能力 / 系统集成 / 未就绪** 分组；
- 单击模块看右侧说明（入口、允许角色、提示）；**双击 / 回车 / 「🚀 进入模块」**弹出登录框；
- 登录框：账户、口令（可切换显示）、错误提示；校验失败写审计并清空口令；
- 校验通过后用 `runtime\pythonw.exe` 启动模块，`cwd` 设为模块目录；
- 右上角：账户管理（仅 owner）、审计日志、使用说明、退出；
- 04 巡考机器人只有文档，树里显示“缺入口”，按钮置灰。

## 2. 账户与权限

独立文件 `总控台账户.json`（PBKDF2-HMAC-SHA256 加盐哈希，不存明文）。
默认值与 03 一致：

| 账户 | 口令 | 角色 | 可进入模块 |
| --- | --- | --- | --- |
| owner | EDY_POWERQ | 所有者 | 全部（`*`） |
| admin | admin | 管理员 | 01/02/03/05/06/07/08/09/10/11/12/13 |
| patrol1 | patrol1 | 巡考员 | 01/02/03/10/11/12 |
| inv01 | inv01 | 监考员 | 03/10 |
| check1 | check1 | 核验员 | 01 |

- owner 可新增账户、重置口令、改“可进入模块”范围、删除账户（至少保留一名 owner）；
- 每次登录/进入（成功与失败）写 `总控台审计.jsonl`；
- 默认口令账户在管理表里标“是”，登录后状态栏提示尽快修改。

**03 自动登录**：总控台把 `EXAM_LAUNCH_USER/PWD/AUTO` 传给 03；
`terminal_gui._launch_auto_login()` 读完立即 `pop` 环境变量，口令不落盘、不写日志。
账户/口令与 03 不一致时，03 显示自己的登录页（不伪造成功）。

## 3. 启动器/打包结构

```
exe打包文件\
  智能考场AI巡考系统.exe     成品（525 MB）
  总控台.py                  目录树 + 登录 + 启动 + 账户管理
  launcher_auth.py           账户存储/校验（PBKDF2）
  模块清单.json              14 个模块的分组/入口/角色
  runtime\                   独立 Python 3.12 + 依赖（508 MB）
  00..13\                    各子系统源码与数据
  _build\
    launcher\main.go         自解压启动器源码
    launcher.exe             已编译启动器
    pack.py                  生成 payload.zip（排除 _build/缓存/日志/附件）
    assemble.ps1             launcher + payload + trailer
```

**重新打包**：

```powershell
cd exe打包文件
runtime\python.exe _build\pack.py
powershell -ExecutionPolicy Bypass -File _build\assemble.ps1
```

## 6. 如实说明

1. **这是界面入口门禁，不是文件系统权限**。能进解压目录的人仍可直接
   `runtime\python.exe <模块脚本>`；要防这一层需要 NTFS ACL 或受控服务端。
2. **各模块内部仍可能有自己的登录**（01/02/05/08/10 等），总控台账户只是“进入模块”
   的统一门禁；03 已做自动带入，其余模块按原账户登录。
3. **默认口令是公开的演示口令**（owner/owner 等），首次登录后务必在
   「账户管理」里改掉。
4. 04 只有方案文档，没有可运行入口。
5. 单文件 exe 约 525 MB，主要来自自带 Python 运行时（508 MB）；首次解压约 873 MB。
   换机器/删掉 `%LOCALAPPDATA%\智能考场AI巡考系统` 后会重新解压。
6. 未做 exe 代码签名；首次运行可能出现 SmartScreen 提示，选“仍要运行”。
