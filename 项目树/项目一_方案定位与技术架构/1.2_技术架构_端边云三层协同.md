# 1.2 技术架构：端 - 边 - 云三层协同

> 所属项目：项目一 · 方案定位与技术架构

## 一、总体架构

| 层级 | 部署位置 | 核心职责 | 关键设备 |
| --- | --- | --- | --- |
| 端侧 | 考场内 | 视频 / 音频采集 | 高清摄像机、拾音器 |
| 边缘侧 | 考点机房 | 实时 AI 推理、告警生成 | AI 分析服务器 + AI 加速卡 |
| 云侧 | 上级指挥中心 | 业务管理、数据汇聚、决策指挥 | 巡考业务平台服务器 |

```
        【端侧】考场内                    【边缘侧】考点机房                【云侧】上级指挥中心
  ┌───────────────────┐          ┌────────────────────────┐        ┌────────────────────────┐
  │ 全景摄像机         │          │ AI 分析服务器           │        │ 巡考业务平台            │
  │ 考生特写摄像机     │ ─视频──▶ │ + Atlas 300V AI 加速卡  │─告警──▶│ 多级权限 / 数据汇聚      │
  │ 通道监控摄像机     │          │ 实时推理 · 告警生成      │ 片段   │ 决策指挥 / 对接集成      │
  │ 全向拾音器         │ ─音频──▶ │ 本地全量视频存储         │ 元数据 │ 复核 · 追溯 · 统计       │
  └───────────────────┘          └────────────────────────┘        └────────────────────────┘
            ▲                                  ▲                                  ▲
            └──────── 教育专网 / MPLS-VPN 专网 ─┴──────────────────────────────────┘
```

## 二、端侧配置

### 2.1 摄像机

| 参数项 | 要求 |
| --- | --- |
| 像素 | 800 万像素 |
| 成像能力 | 星光级、全局快门、HDR 成像 |
| 工作温度 | -20℃ ~ 60℃ 宽温 |
| 最低照度 | 0.002 Lux 超低照度 |
| 考场全景摄像头 | 仰角约 20° ~ 25° |
| 考生特写摄像头 | 俯角约 15° |
| 通道监控 | 双向覆盖 |

> 已有标准化考点**可复用现有设备**，仅需替换老旧摄像机即可接入 AI 分析能力。

### 2.2 拾音器

| 参数项 | 要求 |
| --- | --- |
| 拾音方式 | 全向拾音 |
| 频率响应 | 80Hz ~ 16KHz |
| 灵敏度 | ≥ -34dB |
| 拾音面积 | 覆盖 80 ㎡ |
| 检测目标 | 交谈声、耳机反馈音等异常声音事件 |

## 三、边缘侧配置

### 3.1 部署方案

**方案 A（推荐，中等规模）**

- 华为鲲鹏服务器 + Atlas 300V AI 加速卡
- 单张 AI 卡支持 **50 个考场**
- 一台服务器最多插 **3 张卡**，最大支持 **150 个考场**
- 每张卡算力 **100 TOPS INT**，处理速度 **≥ 60 张/秒**

**方案 B（小规模考点）**

- NVIDIA Jetson AGX Orin 边缘计算节点，算力 275 TOPS，部署 TensorRT 加速引擎
- 可选替代：华为 Atlas 500 Pro、瑞芯微 RK3585 等边缘 AI 盒子

### 3.2 算法能力

| 行为类别 | 覆盖数量 |
| --- | --- |
| 考生个体行为 | 12 种 |
| 考生群体行为 | 8 种 |
| 监考员行为 | 20 种 |
| 考务规范行为 | 4 种 |

- 疑似行为识别提示率 **≥ 98.5%**
- 算法分类应符合教育部《人工智能识别分析异常行为分类参考》

## 四、云侧配置

- 上级指挥中心部署**巡考业务平台**
- 支持**县、市、省级多级管理权限**
- 实现考场异常数据共享和决策指挥
- 需支持与现有**考务管理平台、身份认证系统、网上巡查系统**的对接集成

## 五、网络传输

- 考场摄像机通过**教育专网或 MPLS-VPN 专网**接入考点交换机
- 视频流经边缘节点实时分析后，**仅将告警片段和结构化元数据上传云端**
- **全量视频流本地存储**，降低带宽压力与合规风险
- 边缘端要求支持 **2 路千兆以上**高实时性、低延迟的有线网络传输

## 六、数据流向与存储策略

| 数据类型 | 产生位置 | 传输方式 | 存储位置 | 说明 |
| --- | --- | --- | --- | --- |
| 全量视频流 | 端侧摄像机 | 专网视频流 | 边缘侧本地 | 不上云，按保留期限管理 |
| 告警片段 | 边缘侧 | 加密上传 | 云侧平台 | 供复核与追溯 |
| 结构化元数据 | 边缘侧 | 加密上传 | 云侧平台 | 行为类型、时间、考场、置信度 |
| 复核与处置记录 | 云侧平台 | 内部流转 | 云侧平台 | 形成闭环留痕 |

## 七、指标口径说明（避免与"准确率"混用）

- **疑似行为识别提示率 ≥98.5%**：召回率口径（正确提示 ÷ 实际异常），属**算法灵敏度/能力指标**，不作为验收判定条件。
- **行为识别精确率 ≥95%**：即"误报率 ≤5%"的正反表述（复核成立告警 ÷ 告警总数），是**唯一决定验收结论的算法类主指标**。
- **误报率相对下降 67%**：优化前后的相对改善幅度，属过程指标，与绝对误报率不是同一口径。

> 全文指标以**项目书附录 B《核心指标汇总表（唯一权威口径）》**为准。
