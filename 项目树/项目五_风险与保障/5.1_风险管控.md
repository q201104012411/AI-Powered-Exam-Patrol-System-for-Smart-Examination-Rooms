# 5.1 风险管控

> 所属项目：项目五 · 风险与保障

## 一、风险清单与应对措施

| 风险类型 | 具体风险 | 应对措施 |
| --- | --- | --- |
| 技术风险 | 算法误报率高，增加人工复核负担 | 试点阶段充分验证，动态调整阈值；建立误报反馈闭环 |
| 技术风险 | 考场光线、角度差异影响识别效果 | 部署前逐考场标定，调整摄像机角度和算法参数 |
| 合规风险 | 考生对人脸采集有抵触情绪 | 考前充分告知，提供非人脸核验替代通道 |
| 合规风险 | 数据泄露风险 | 加密存储、权限管控、审计留痕、到期销毁 |
| 运营风险 | 考务人员不熟悉系统操作 | 全覆盖培训 + 模拟演练，编制操作手册 |
| 运营风险 | 网络不稳定导致系统中断 | 边缘端断网降级模式，本地缓存告警数据 |
| 区域公平风险 | 不同区域部署进度不一致 | 统筹规划，分批次推进，确保考试前全部到位 |

## 二、已知实践挑战

- **技术判断局限性**：如区分"挠痒"与"作弊手势"存在困难，需通过人工复核兜底
- **隐私保护制度衔接不足**：需在制度与流程层面同步建设，而非仅靠技术手段
- **资源配置不均衡**：可能导致部分考点应用支持不足，需在培训阶段做好全覆盖保障

## 三、风险监控机制（建议）

| 机制 | 频率 | 责任人 |
| --- | --- | --- |
| 误报率专项统计 | 每次考试后 | 平台运维 + 考务管理 |
| 合规自查 | 每学期 | 数据安全责任人 |
| 演练与预案更新 | 考前至少一次 | 考点考务组 |
| 区域进度通报 | 每周（实施期内） | 项目管理层 |
