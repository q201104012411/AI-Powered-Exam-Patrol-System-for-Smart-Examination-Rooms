# 5.2 供应商选择

> 所属项目：项目五 · 风险与保障

## 一、候选供应商对比

| 供应商 | 核心产品 / 方案 | 优势领域 |
| --- | --- | --- |
| 华为 + 佳发教育 | 智能巡考联合解决方案 | 已在 10 余省份、500 多个考点、30000 多个考场规模化部署 |
| 中国电信 | AI 智慧巡考平台 | 福建全省覆盖 255 个考点、近万间考场，自研 40 余种 AI 算法 |
| 海康威视 | 智能抽签及身份识别系统 | 人脸识别硬件设备成熟 |
| 眼神科技 | 多模态生物识别身份认证平台 | 金融级人脸识别算法 |

## 二、供应商评估维度

| 评估维度 | 评估要点 |
| --- | --- |
| 算法准确率 | 要求提供第三方检测报告（CMA / CNAS） |
| 现有标考系统兼容性 | 与既有标准化考点设备、考务平台的对接能力 |
| 国产化信创支持能力 | 服务器、加速卡、操作系统、数据库的信创适配 |
| 本地化服务团队配置 | 本地驻点 / 响应半径，2 小时远程、4 小时到场可达性 |
| 类似项目落地案例数量 | 同层级（省/市/区县）规模化案例 |
| 系统集成对接能力 | 与考务管理平台、身份认证系统、网上巡查系统的对接经验 |

## 三、评分建议（100 分制参考）

| 评分项 | 权重 |
| --- | --- |
| 技术方案与算法能力 | 30 |
| 第三方检测与合规材料 | 15 |
| 信创与兼容性 | 15 |
| 案例与履约能力 | 15 |
| 服务与运维体系 | 15 |
| 报价合理性 | 10 |
