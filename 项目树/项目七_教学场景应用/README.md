# 项目七 · 教学场景应用

> 定位：回答"这套系统**除了考试还能干什么**"——把考试期建设的端-边-云能力，在**非考试期的日常教学**中复用，让 AI 充当"电子巡课教师"。
> 一句话概括：**考试模式管考场（见项目六·10），教学模式管课堂（见本专题）。**

## 二、两种场景，两套规则（核心对照）

| 维度 | 考试模式（项目六·10） | 教学模式（本专题） |
| --- | --- | --- |
| 开启策略 | 考试时段全程开启 | **课表联动、按需开启**，非教学时段关闭或遮蔽 |
| 授权基础 | 考生**单独同意**（考前） | 学生/监护人告知同意 + 教师同意 |
| 分析目的 | 作弊线索发现与处置 | 课堂秩序提示与教研改进 |
| 展示粒度 | 可回溯个体片段（按权限） | **默认班级聚合**，个体画面仅教师即时可见 |
| 数据留存 | 按考务规定（建议 30 天起） | 教研录像建议 ≤15 天 |
| 禁止事项 | 禁止情绪分析、超范围使用 | **禁止学生个体评价、排名、与成绩/评优挂钩，禁止情绪与心理推断** |

## 三、三种运行模式（按学校治理要求选择）

| 模式 | 开启内容 | 适用学校 |
| --- | --- | --- |
| 极简模式 | 仅录播 + 到课统计 | 对隐私最敏感、仅需教研回放 |
| 标准模式 | 录播 + 到课 + 课堂秩序提示（教师端） | 多数学校推荐 |
| 完整模式 | 标准模式 + 教学行为观察 + AI 巡课报告 | 有教研数字化基础的学校 |

## 五、推广建议与风险提示

| 阶段 | 动作 |
| --- | --- |
| 试点期 | 选 1 间教室、1 个学科验证可行性，先出教师侧体验反馈 |
| 推广期 | 按"极简 → 标准 → 完整"逐档放开，先取得教师群体认同 |
| 成熟期 | 与教务课表、教研平台打通，形成常态化巡课报告 |

**风险提示**：教学场景最易踩的坑是"以教学之名长期录制"。必须做到课表联动自动启停、非教学时段关闭率 100% 并有记录可查，且明确**不得用于学生个体评价、排名、成绩与评优挂钩**。
