# 教学场景：AI 教师巡视教室

> 所属：项目七 · 教学场景应用 ｜ 专题 01
> 定位：把考试期间建设的端-边-云能力，在**非考试期的日常教学**中复用起来，由 AI 充当"**电子巡课教师**"，模拟教师巡视教室、教研听课与教学督导。

## 一、场景价值

| 价值点 | 说明 |
| --- | --- |
| 资产复用 | 考试设备一年仅使用数十天，教学期复用可显著提升投资回报率 |
| 减负 | 替代人工巡课、听课记录、到课统计等重复性工作 |
| 教学改进 | 以数据支撑教研，而非以数据评价学生 |
| 安全兜底 | 教学期突发事件（学生晕倒、打闹）可及时发现 |

## 二、功能清单

| 功能 | 说明 | 输出对象 |
| --- | --- | --- |
| 到课统计 | 刷卡/签到为主，教师端确认兜底；**不强制刷脸** | 班主任、教务 |
| 课堂秩序提示 | 趴桌、随意走动、后排聚集等，**实时提示授课教师** | 授课教师（当场提示，不留学生标签） |
| 教学行为观察 | 教师讲授时长、走动范围、提问次数、板书时长 | 教师本人 + 教研组（需教师同意） |
| 课堂互动统计 | 举手、应答、小组讨论活跃度（班级聚合） | 教研组 |
| 课堂录播回放 | 教研听课、优质课留存、新教师带教 | 教研组 |
| AI 巡课报告 | 周/月报：到课率、秩序事件、教学行为指标 | 教务管理者 |
| 突发事件告警 | 学生跌倒、长时间无人看管等 | 值班教师、安保 |

## 三、与考试模式的关键区别（务必区分）

| 维度 | 考试模式 | 教学模式 |
| --- | --- | --- |
| 开启时段 | 考试时段全程开启 | **课表联动，按需开启**，非教学时段关闭或物理遮蔽 |
| 授权方式 | 考生单独同意（考前） | 学生/监护人告知同意 + 教师同意（教研数据） |
| 分析对象 | 考生作弊相关行为 | 课堂秩序与教学行为，**不作学生个体评价** |
| 展示方式 | 可回溯个体片段 | **默认班级聚合展示**，个体画面仅教师即时可见 |
| 数据留存 | 按考务规定（建议 30 天起） | 教研录像建议 ≤ 15 天，统计类数据可保留至学期末 |
| 用途限定 | 仅作弊判定 | 仅教学管理与教研改进，**不得与成绩、评优挂钩** |

## 四、运行模式设计

1. **课表联动**：与教务课表对接，仅在排课教室、排课时段开启；空堂、假期自动关闭。
2. **一键隐私模式**：教师可在终端一键关闭分析（保留录播或全关），关闭动作留痕。
3. **分级开启**：教务可配置"仅录播 / 录播+秩序提示 / 全功能"三档，按学校治理要求选择。
4. **模式切换审批**：考试模式 ↔ 教学模式切换需授权并记录，防止以"教学"名义长期录制。

## 五、技术实现

- 复用项目一的端-边-云架构与项目六的智能终端、摄像头核查能力
- 边缘节点加载**教学场景算法包**（与考试算法包物理/逻辑隔离，避免模型误用）
- 教学数据与考试数据**分域存储**，不混库、不共用索引
- 报告自动生成，支持导出与教研会议使用

## 六、合规红线（教学场景更需要谨慎）

1. **禁止情绪与心理推断**：不得输出"学生注意力/情绪/心理状态"等个体推断结论（考试场景已明确禁止，教学场景同样适用）。
2. **禁止个体画像与排名**：不得生成学生个人行为评分、排名，不得与成绩、评优、处分挂钩。
3. **同意与告知**：涉及学生个人影像分析须经学生/监护人告知同意，并在班级、家长会公示说明。
4. **教师数据边界**：教学行为数据用于教师本人改进与教研，不得直接用于考核处罚，需在制度中明确。
5. **最小必要**：默认班级聚合、默认短留存、默认不采集音频或仅本地处理。
6. **不得作为处分依据**：AI 提示仅作线索，纪律问题须人工核实并按校规处理。

## 七、关键指标

| 指标项 | 要求 |
| --- | --- |
| 到课统计准确率 | ≥ 98% |
| 秩序事件识别召回率 | ≥ 90%（教学场景为提示性质，容忍一定误报） |
| 提示时延（教师端） | ≤ 5 秒 |
| 巡课报告生成 | 当日自动生成 |
| 非教学时段设备关闭率 | 100%（含自动遮蔽/断电记录） |
| 违规用途事件 | 0 起（审计验证） |
