# 3.2 技术合规措施

> 所属项目：项目三 · 合规与数据治理

按"采集 — 处理 — 存储 — 使用"四个层面落实合规要求。

## 一、采集层

- 摄像头调用必须有**明确的考前授权**，不能静默开启
- 采集频率**按需最小化**，不需每秒 30 帧
- 人脸信息采集前完成单独告知与单独同意

## 二、处理层

- 人脸特征数据**加密或脱敏存储**
- AI 推理过程需输出**可解释的判定依据**，不能只输出"疑似作弊"
- 判定依据应包含：行为类别、时间点位、置信度、触发规则

## 三、存储层

| 要求项 | 措施 |
| --- | --- |
| 保留期限 | 视频/图片设定明确保留期限（建议考试结束后 **30 天**），到期自动删除 |
| 存储加密 | 静态数据加密存储 |
| 访问审计 | 全量访问行为留痕，形成审计日志 |

## 四、使用层

- 监考数据**仅用于考试作弊判定**，不得用于情绪分析等其他目的
- 考生**有权要求查阅和删除**自己的数据
- 数据导出、共享须经授权审批并留痕

## 五、合规控制点汇总表

| 层面 | 控制点 | 验收证据 |
| --- | --- | --- |
| 采集 | 考前授权、非静默开启、频率最小化 | 授权记录、配置截图 |
| 处理 | 特征脱敏、可解释输出 | 脱敏方案、判定依据样例 |
| 存储 | 期限管控、加密、审计 | 自动删除策略、加密证明、审计日志 |
| 使用 | 目的限定、权利响应 | 权限矩阵、查阅/删除工单记录 |
