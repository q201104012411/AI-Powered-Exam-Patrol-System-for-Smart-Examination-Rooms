# 3.1 法律依据

> 所属项目：项目三 · 合规与数据治理

## 一、遵循的法律法规

| 法律法规 | 核心要求 | 在本方案中的落地要点 |
| --- | --- | --- |
| 《个人信息保护法》 | 告知同意、最小必要、目的限定 | 人脸信息处理须取得**单独同意**，不得捆绑 |
| 《数据安全法》 | 数据分类分级、安全保护义务 | 视频、人脸特征、告警数据分级存储与加密 |
| 《人脸识别技术应用安全管理规定》 | 人脸识别的严格适用条件 | 非必要不采集；提供替代核验通道 |

## 二、关键合规红线

1. **单独同意**：涉及人脸信息处理时**必须取得考生单独同意**，不能捆绑在一般考试规则中。
2. **目的限定**：采集数据仅用于考试作弊判定，不得用于情绪分析等其他目的。
3. **最小必要**：采集频率、采集范围、存储期限均应满足最小必要原则。
4. **可解释**：AI 推理需输出可解释的判定依据，不得仅输出"疑似作弊"。
5. **可主张权利**：考生有权要求查阅和删除自己的数据。
