# 3.3 数据安全架构

> 所属项目：项目三 · 合规与数据治理

## 一、统一身份认证机制

- 搭建**统一身份认证**机制
- 结合**登录地点、使用设备、访问时段**等信息开展**持续校验**
- 划分**精细化操作权限**（按角色 × 数据范围 × 操作类型）

## 二、权限模型（建议）

| 角色 | 数据范围 | 主要权限 |
| --- | --- | --- |
| 省级巡考管理员 | 全省 | 汇聚查看、统计分析、跨区域调度 |
| 市级巡考管理员 | 本市 | 汇聚查看、考点管理、告警复核抽查 |
| 区县级巡考管理员 | 本区县 | 考点查看、告警处置跟踪 |
| 考点巡考员 | 本考点 | 告警复核、现场处置记录 |
| 监考员 | 本考场 | 接收告警提示（最小必要视图） |
| 系统运维员 | 设备与日志 | 设备状态、故障处理（无业务数据明文权限） |

## 三、终端设备准入

- 针对**考场摄像头、巡考电脑**等终端设备进行安全检测
- **仅允许合规设备接入网络**（准入控制：设备指纹、证书、白名单）
- 异常终端自动阻断并告警

## 四、安全技术措施清单

| 措施 | 说明 |
| --- | --- |
| 传输加密 | 告警片段与元数据经专网加密上传 |
| 存储加密 | 视频、图片、人脸特征加密存储 |
| 脱敏展示 | 客户端默认脱敏展示，必要时授权解密查看 |
| 审计留痕 | 登录、查询、导出、删除全量日志 |
| 到期销毁 | 按保留期限自动删除并生成销毁记录 |
| 断网降级 | 边缘端本地缓存告警数据，恢复后补传 |
