# 人脸识别与身份核对

> 所属：项目六 · 智能化装备与考生数据保护 ｜ 专题 01

## 一、建设目标

在不改变现有入场流程的前提下，用生物特征核验替代/辅助人工核验，实现"**人、证、票、座**"四要素一致，从源头阻断替考。

## 二、应用场景与功能

| 场景 | 功能 | 部署位置 | 部署方式 |
| --- | --- | --- | --- |
| 考点入场核验 | 人脸 + 身份证 + 准考证 三合一核验，1:1 比对 | 考点入口 / 考场楼门厅 | 核验闸机或核验终端 |
| 考场签到核验 | 考生入场刷脸签到，自动比对报名库 | 考场门口 | 手持核验终端 / 壁挂终端 |
| 考场内抽查复核 | 监考员按座次随机抽查，1:N 比对 | 考场内 | 手持终端 |
| 替考嫌疑预警 | 核验失败多次 / 特征相似度异常触发复核 | 平台侧 | 规则 + 算法 |
| 监考员身份核验 | 监考员签到、随机抽签、跨考场回避 | 考务办 | 终端 + 平台 |
| 特殊情形处置 | 受伤、面部遮挡、整容等无法核验 | 考点 | 人工核验 + 双人见证留痕 |

## 三、关键技术指标

| 指标项 | 要求 |
| --- | --- |
| 人脸识别误识率 | ≤ 0.1%（第三方 CNAS/CMA 报告） |
| 人脸识别拒识率 | ≤ 1%（同上） |
| 1:1 比对速度 | ≤ 1 秒 |
| 1:N 比对速度 | ≤ 3 秒 |
| 活体检测 | 防照片、防视频回放、防 3D 面具/头模攻击 |
| 核验通过效率 | ≥ 30 人/分钟/通道 |
| 弱光/逆光适应性 | 支持宽动态，0.002Lux 低照度可用 |
| 口罩/眼镜容忍 | 支持常规佩戴情形下的核验 |

## 四、技术实现要点

1. **特征模板不可逆**：本地仅存储不可逆特征模板，不存储原始人脸图像；确需留存图像的，单独加密并设最短保留期。
2. **多模态兜底**：人脸 + 指纹/身份证芯片信息/人工核验，形成多因子核验，避免单一模态失败堵点。
3. **本地优先**：核验在考点本地完成，断网时启用本地特征库，联网后补传核验记录。
4. **防伪与审计**：核验过程生成带时间戳、设备编号、核验结果的记录，纳入审计日志。

## 五、合规要求（硬约束）

- **单独同意**：人脸信息处理必须取得考生**单独同意**，不得捆绑在一般考试规则中。
- **替代通道**：必须提供**非人脸核验替代通道**（如人工核验 + 双证比对 + 双人见证），考生可自主选择。
- **告知前置**：考前告知核验目的、方式、保留期限与考生权利。
- **目的限定**：核验数据仅用于身份核对与替考判定，禁止用于情绪分析等用途。

## 六、验收与检测

- 第三方检测报告（CNAS/CMA）覆盖误识率、拒识率
- 实际考试场景核验通过率、平均核验耗时
- 活体检测防攻击测试记录（照片/视频/面具三类攻击样本）
- 替代通道可用性验证记录
