# 智能安检与手机作弊器材检测（自主补充）

> 所属：项目六 · 智能化装备与考生数据保护 ｜ 专题 06
> 补充理由：AI 巡考属"事后发现"，安检属"事前阻断"，两者叠加才能覆盖手机、无线耳机等最主流的作弊路径。

## 一、建设内容

| 环节 | 设备 | 作用 |
| --- | --- | --- |
| 考点入口安检 | 智能安检门（电磁感应/毫米波） | 快速筛出手机、无线耳机、金属作弊器材 |
| 复检通道 | 手持金属探测器 + 人工复检 | 对报警考生复检确认 |
| 手机集中保管 | 智能储物柜（人脸/扫码开柜） | 手机统一存放，取件留痕 |
| 鞋底/隐蔽部位检测 | 鞋底检测仪（可选） | 应对鞋内藏匿设备 |
| 数据联动 | 安检记录与身份核验关联 | 形成"人—物—时"闭环记录 |

## 二、关键指标

| 指标项 | 要求 |
| --- | --- |
| 手机（含关机状态）检出率 | ≥ 99% |
| 无线耳机检出率 | ≥ 95% |
| 误报率 | ≤ 5% |
| 单人通过效率 | ≥ 20 人/分钟（不成为入场瓶颈） |
| 孕妇/植入医疗器械考生 | 提供人工安检替代通道 |

## 三、实施要点

1. **流程衔接**：安检—核验—签到三点位串联，避免重复排队；设置备用通道防止拥堵。
2. **特殊考生预案**：体内植入医疗器械、孕妇等考生走人工安检通道，单独记录、双人见证。
3. **保管闭环**：储物柜与考生身份绑定，存取记录可追溯，避免手机丢失纠纷。
4. **合规**：安检告知前置，检测数据仅用于考试安全，不用于其他目的。

## 四、验收证据

- 检出率/误报率实测记录（含关机手机、无线耳机样本测试）
- 入场效率实测与高峰期疏导演练记录
- 特殊考生替代通道演练记录

## 五、工程实现（已落地，2026-10）

本专题已有**可运行实现**（目录即本目录），零第三方依赖（只用标准库 tkinter/sqlite3），
双击 `启动.bat` 即用；详细说明见[使用说明.md](使用说明.md)，自检 `python 自检.py`（138 项）。

| 建设内容 | 实现文件 | 说明 |
| --- | --- | --- |
| 智能安检门接入 | `gate.py` | HTTP `POST /api/pass` / TCP 行协议 / 串口 / 内置模拟器 / 人工录入 |
| 判据引擎（检出算法） | `gate.py` `decide()` | 六路感应强度 -> 橙/红报警；≥2 路报红（双判据确认），单路报橙+复检；阈值可调 + 三档模式 |
| 设备与通道台账 | `storage.py` `devices` | 灵敏度逐台可调、心跳与探活、在线率 |
| 复检与处置 | `reinspect.py` | 派单、操作人必填、结论白名单、SLA 催办、超时上报 03、查获自动入柜 |
| 手机集中保管 | `locker.py` | 柜格台账、人脸/扫码开柜、存取留痕、超时未取、丢失追溯、应急开柜须写理由 |
| 特殊考生替代通道 | `special.py` | 孕妇/植入医疗器械登记，**双人见证硬校验**，演练记录（drill 标记） |
| 入场流程衔接 | `flow.py` | 安检-核验-签到三点位串联与顺序校验、瓶颈点位、人/分钟效率、排队分级疏导 |
| 检出率/误报率证据 | `samples.py` + `report.py` | 样本库 20 条（含关机手机、无线耳机、无害物、植入医疗器械）、判据回放/现场实测、Markdown+CSV 报告 |
| 数据联动（人-物-时） | `linkage_bridge.py` + `00_集成联动` | 报警进 03 智能终端分级处置；过检记录带考生号/座位/考场，与身份核验关联 |
| 界面 | `app.py` | 七个页签：总览 / 设备与通道 / 过检与报警 / 手机保管柜 / 特殊考生通道 / 样本测试与验收 / 设置 |

**报告口径（写在报告第十章「如实说明」里）**：检出率只来自样本测试（有 ground truth），
误报率只来自无害样本；判据回放不能充作整机实测证据，缺实测数据时报告明确标注「整机实测证据：缺失」；
模拟器数据 `source=sim` 不计入任何检出率/误报率。
