# 考生数据保护

> 所属：项目六 · 智能化装备与考生数据保护 ｜ 专题 05
> 与 [项目三 · 合规与数据治理](../../项目三_合规与数据治理/3.1_法律依据.md) 配套执行，本专题聚焦**工程实现与可核查证据**。

## 一、数据分类分级

| 数据类别 | 敏感级别 | 典型内容 | 存储位置 | 保留期限 |
| --- | --- | --- | --- | --- |
| 人脸特征模板 | 高（敏感个人信息） | 不可逆特征向量 | 考点本地 + 加密库 | 考试结束后 30 天 |
| 人脸原始图像 | 高 | 核验抓拍图 | 本地加密 | 最短必要（建议 ≤ 30 天） |
| 考场视频 | 高 | 全量视频流 | 边缘侧本地 | 按当地考务规定，建议 30 天起 |
| 告警片段与元数据 | 中高 | 异常片段、结构化记录 | 云侧平台 | 30 天～1 个考期 |
| 复核与处置记录 | 中 | 结论、理由、附件 | 云侧平台 | 按考务档案要求 |
| 身份报名信息 | 高 | 姓名、证件号、准考证 | 既有考务系统 | 沿用既有规定 |

## 二、全生命周期控制

| 阶段 | 控制措施 | 可核查证据 |
| --- | --- | --- |
| 采集 | 考前单独同意、非静默开启、频率按需最小化（不强制 30fps） | 同意记录、授权日志、采集参数配置 |
| 传输 | 专网传输 + 加密（国密优先），告警片段与元数据加密上传 | 加密配置、链路说明 |
| 存储 | 特征模板不可逆、原始图像单独加密、分类分级存储 | 加密证明、模板不可逆说明 |
| 使用 | 目的限定（仅作弊判定）、脱敏展示、最小权限、水印溯源 | 权限矩阵、脱敏截图、水印样例 |
| 共享 | 跨层级共享仅传必要字段，导出需审批 | 审批工单、导出审计日志 |
| 销毁 | 到期自动删除 + 销毁记录，介质报废按规处理 | 删除策略配置、销毁记录台账 |

## 三、工程化技术措施

1. **不可逆特征存储**：人脸比对只落特征模板，不落原图；确需留图的单项加密并设最短期限。
2. **去标识化展示**：巡考客户端默认以编号/座次展示，人脸图像需授权解密查看，且查看行为全程留痕。
3. **动态水印**：视频回看与截图自动叠加"操作人+时间+终端"水印，防外泄溯源。
4. **最小权限 + 持续校验**：结合登录地点、设备、时段动态校验（见 [3.3 数据安全架构](../../项目三_合规与数据治理/3.3_数据安全架构.md)）。
5. **到期自动销毁**：存储策略与销毁任务由系统强制执行，不接受人工"忘记删除"的例外，销毁生成不可篡改记录。
6. **禁止出境与超范围使用**：数据不得用于情绪分析、行为画像、商业用途，不得跨境传输。

## 四、管理措施

| 措施 | 内容 |
| --- | --- |
| 数据安全责任人 | 明确到人，纳入项目组与考点两级 |
| 个人信息保护影响评估（DPIA） | 上线前完成，评估报告归档 |
| 权限审批 | 高敏数据访问与导出走审批，定期复核权限 |
| 应急响应 | 泄露事件 2 小时内上报并按预案处置，留存处置记录 |
| 培训 | 面向考务与运维人员的合规与操作培训，签到留档 |

## 五、考生权利响应

| 权利 | 响应方式 | 时限建议 |
| --- | --- | --- |
| 知情 | 考前告知书、考点公示 | 考前 |
| 查阅、复制 | 受理申请，核验身份后提供 | 5 个工作日内 |
| 更正 | 核对后更正并留痕 | 5 个工作日内 |
| 删除 | 无法律保留必要时删除并出具记录 | 10 个工作日内 |
| 撤回同意 | 提供非人脸核验替代通道，不影响考试权利 | 即时 |

## 六、验收指标

| 指标项 | 要求 |
| --- | --- |
| 敏感数据加密率 | 100% |
| 操作审计覆盖率 | 100%（登录、查询、导出、删除） |
| 到期自动销毁执行率 | 100%，销毁记录可查 |
| 越权访问测试 | 全部拦截 |
| 替代通道可用性 | 100% 考点可用并有演练记录 |
