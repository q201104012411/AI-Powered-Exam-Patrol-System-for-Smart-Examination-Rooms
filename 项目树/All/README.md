## 五、共性合规要求（所有专题通用）

1. **单独同意**：人脸信息处理取得考生单独同意，不捆绑一般考试规则。
2. **替代通道**：任何智能环节都必须保留人工/非人脸替代路径。
3. **目的限定**：数据仅用于考试安全与作弊判定，禁止情绪分析、行为画像等超范围使用。
4. **最小必要**：采集范围、频率、保留期限均按最小必要设置，建议考试结束后 30 天自动删除。
5. **留痕可审**：设备操作、数据访问、告警处置全链路留痕，接受审计。
