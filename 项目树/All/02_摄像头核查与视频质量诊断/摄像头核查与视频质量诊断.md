# 摄像头核查与视频质量诊断

> 所属：项目六 · 智能化装备与考生数据保护 ｜ 专题 02

## 一、建设目标

确保全量摄像头"**看得见、看得清、看得全、没被动过、录得下来**"，把设备故障和人为干扰发现在开考之前。

## 二、核查内容

| 核查类别 | 具体项 | 判定方式 |
| --- | --- | --- |
| 在线状态 | 设备在线/离线、取流失败、心跳丢失 | 平台轮询 + 心跳 |
| 图像质量 | 画面模糊、失焦、偏色、过曝/过暗、条纹、雪花、冻结帧、马赛克 | 视频质量诊断算法 |
| 视野完整性 | 遮挡、喷涂、贴纸、镜头被转向、视角偏移 | 基准图比对 + 遮挡检测 |
| 录像完整性 | 存储是否连续、有无丢帧/丢段、录像可回放 | 录像索引核查 |
| 时间一致性 | 各摄像机与平台时钟是否一致（NTP） | 时间戳比对 |
| 音频链路 | 拾音器在线、音量正常、无持续噪声 | 音频电平检测 |
| 设备台账 | 设备编码与考场对应关系、安装位置、角度参数 | 台账核对 |

## 三、巡检策略（三级）

| 级别 | 时点 | 范围 | 输出 |
| --- | --- | --- | --- |
| 日常自动巡检 | 每 30 分钟 | 全部考点 | 在线率、质量异常清单 |
| 考前专项核查 | 考前 7 天 | 全部考场 | 逐考场核查报告、整改工单 |
| 考前一小时自检 | 每场开考前 30 分钟 | 本场全部机位 | 自检通过确认、异常即时报修 |

## 四、技术实现要点

1. **基准图机制**：部署完成后逐机位采集基准图与标准角度参数，后续按固定周期抓帧比对，偏移超阈值即告警。
2. **多算法融合**：无参考图像质量评价 + 遮挡检测 + 帧间差异检测，降低误判。
3. **闭环整改**：异常自动生成工单，支持"发现—派单—整改—复核"闭环，整改前后截图留档。
4. **与巡考联动**：质量异常点位的告警可信度自动降权，避免因画质问题造成误报堆积。

## 五、关键指标

| 指标项 | 要求 |
| --- | --- |
| 摄像机在线率（考试期间） | ≥ 99% |
| 故障自动发现时延 | ≤ 5 分钟 |
| 覆盖完整性核查 | 考场无死角、无盲区，覆盖率 100% |
| 考前核查完成率 | 100%（逐机位留档） |
| 时钟一致性偏差 | ≤ 1 秒 |

## 六、验收证据

- 逐考场/逐机位核查报告（含基准图与整改前后对比图）
- 考前专项核查记录与整改闭环记录
- 在线率与故障处理时效统计（试运行期）
