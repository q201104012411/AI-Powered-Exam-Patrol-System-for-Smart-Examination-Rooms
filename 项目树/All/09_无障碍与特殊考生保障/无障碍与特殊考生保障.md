# 无障碍与特殊考生保障（自主补充）

> 所属：项目六 · 智能化装备与考生数据保护 ｜ 专题 09
> 补充理由：智能化设备天然带来"技术门槛"，必须为特殊考生预留替代路径，否则会形成新的不公平，也是合规评审的高频质疑点。

## 一、适用对象

| 对象 | 主要困难 | 保障措施 |
| --- | --- | --- |
| 面部损伤/术后/严重痤疮考生 | 人脸核验失败 | 人工核验 + 双证比对 + 双人见证 |
| 视力障碍考生 | 刷脸设备操作困难 | 语音引导终端 + 工作人员协助 |
| 肢体障碍/轮椅考生 | 安检门与核验终端高度不适配 | 低位核验终端、加宽通道、人工安检 |
| 听力障碍考生 | 语音播报听不到 | 文字/震动提示、监考员书面提示 |
| 佩戴医疗器械考生 | 安检门报警 | 人工安检替代通道，凭证明放行 |
| 少数民族/外籍考生 | 姓名与证件格式差异 | 人工核验兜底，系统支持多字符集 |

## 二、建设要求

1. **三通道并行**：每个考点至少设置"智能核验通道 + 人工核验通道 + 无障碍专用通道"。
2. **低位与加宽**：至少 1 条通道满足轮椅通行（净宽 ≥ 900mm）与低位核验终端（高度可调）。
3. **语音+文字双提示**：核验与告警提示同时提供视觉与听觉两种方式。
4. **人工兜底不可取消**：任何情况下不得因设备原因拒绝考生入场，人工核验结论与智能核验具有同等效力。
5. **算法公平性评估**：上线前对核验算法做分层测试（性别、年龄、有无眼镜/口罩等），差异显著时调整阈值或补偿策略。

## 三、关键指标

| 指标项 | 要求 |
| --- | --- |
| 无障碍通道配置率 | 100% 考点 |
| 替代核验通道可用性 | 100%，且每考期至少演练 1 次 |
| 因技术原因未能入场事件 | 0 起 |
| 算法分层测试 | 覆盖主要人群分层，差异在可接受范围 |

## 四、验收证据

- 无障碍通道现场照片与尺寸核验记录
- 替代核验流程演练记录与操作手册
- 算法分层测试报告（含差异分析与阈值调整说明）
- 特殊考生处置台账样例（脱敏）
