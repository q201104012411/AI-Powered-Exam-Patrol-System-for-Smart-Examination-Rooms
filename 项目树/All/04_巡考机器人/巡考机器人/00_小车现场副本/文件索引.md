## 五、快速上手

```bash
# 1) 启动底盘 + 相机（另开终端）
roslaunch turn_on_wheeltec_robot turn_on_wheeltec_robot.launch
roslaunch turn_on_wheeltec_robot wheeltec_camera.launch

# 2) 网页
cd ~/patrol_robot/webui && python3 robot_web.py     # http://<小车IP>:8080/

# 3) 相机快照服务（网页三路画面需要）
cd ~/patrol_robot && python tools/snapshot_server.py &

# 4) 巡线
cd ~/patrol_robot && ./run_line_patrol.sh

# 5) 巡逻
cd ~/patrol_robot && ./run_patrol.sh --route route_classroom_ros1.yaml
```

## 六、改代码的正确姿势

1. 改 `tools/line_follow_white.py`（巡线）或 `patrol_move_ros1.py`（巡逻）
2. **网页"参数/代码" → 文件快捷方式 → 选中文件 → 编辑 → 保存文件**（自动 py2 语法校验 + 备份 .bak）
3. 点"▶ 一键跟随黑绳"重启即生效

## 七、安全提醒

- **雷达和相机抢 USB**：相机全开时雷达可能"活着但不发数据"，跑避障时先关 USB 相机
- **杀驱动前必须先发零速**（否则 STM32 锁住最后的速度）
- **底盘低速死区 ≈0.12 m/s**：低于此速度完全不动
- **电池 <21V 会掉电重启**；<24V 时扭矩不足，转向打不出来
