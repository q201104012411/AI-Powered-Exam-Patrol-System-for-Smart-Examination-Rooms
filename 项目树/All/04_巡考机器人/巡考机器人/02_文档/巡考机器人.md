# 巡考机器人

> 所属：项目六 · 智能化装备与考生数据保护 ｜ 专题 04

## 一、定位与边界（重要）

巡考机器人用于**替代重复性人工巡楼与值守**，部署范围以**考点公共区域**为主：

| 区域              | 是否部署  | 说明                              |
| --------------- | ----- | ------------------------------- |
| 考点楼道、连廊、警戒线外围   | ✅ 推荐  | 秩序巡查、越界提醒、夜间值守                  |
| 试卷保密室、考务办、机房    | ✅ 推荐  | 定时巡查、环境异常检测、非接触值守               |
| 考点大门、候考区        | ✅ 可用  | 人流秩序、聚集提醒                       |
| **考场内部（考试进行中）** | ❌ 不部署 | 移动机体可能产生噪声、视线干扰与考生注意力分散，且存在合规争议 |

> 结论：**考场内异常识别仍由固定摄像机 + 边缘 AI 承担**（见项目一）；机器人负责"考场外"这一人工巡考强度最大的环节。

## 二、功能配置

| 功能模块      | 说明                           |
| --------- | ---------------------------- |
| 自主导航与避障   | 激光雷达 + 视觉 SLAM，支持电梯/门禁联动（可选） |
| 定时巡更      | 按班次/路线自动巡逻，巡更点位打卡留痕          |
| 视频与热成像    | 云台摄像机 + 红外热成像，支持夜间巡查         |
| 异常事件检测    | 人员聚集、越界闯入、徘徊、吸烟、遗留物品、明火      |
| 双向对讲与语音提醒 | 远程喊话、自动安全提示（如"请勿在警戒线内停留"）    |
| 环境感知      | 温湿度、烟雾、水浸（保密室/机房场景）          |
| 自动回充      | 低电量自主返回充电，充电期间任务自动接管         |
| 巡查报告      | 自动生成巡更轨迹、事件清单、异常截图           |

## 三、关键技术参数（建议）

| 参数项  | 建议值                      |
| ---- | ------------------------ |
| 续航时间 | ≥ 8 小时（支持自动回充续巡）         |
| 导航精度 | ≤ 5 cm（重复到位精度）           |
| 越障能力 | ≥ 2 cm 台阶，≥ 5° 爬坡        |
| 通信   | 双频 WiFi / 专网，支持断网本地巡检与缓存 |
| 云台   | 水平 360°、垂直 ±90°，支持预置位巡航  |
| 防护等级 | ≥ IP54（室外/半室外场景）         |
| 安全   | 防跌落、防碰撞急停、紧急制动按钮         |

## 四、与巡考体系的协同

1. **事件统一入池**：机器人发现的异常事件以标准结构化格式上报巡考业务平台，与固定摄像机告警**同一队列、同一复核流程**，避免多套系统割裂。
2. **人机分工**：固定摄像机负责考场内行为识别 → 边缘 AI 告警；机器人负责公共区域秩序与人流 → 平台告警；人工负责最终裁定。
3. **夜间/非考试时段**：机器人承担保密室与重点区域的非考试时段巡查，形成"考试时段靠 AI 巡考、非考试时段靠机器人巡更"的互补。

## 五、考核指标

| 指标项             | 要求        |
| --------------- | --------- |
| 巡更任务完成率         | ≥ 99%     |
| 定位与到位精度         | ≤ 10 cm   |
| 异常事件上报时延        | ≤ 5 秒     |
| 单次充电连续工作时长      | ≥ 8 小时    |
| 平均无故障运行时间（MTBF） | ≥ 2000 小时 |

## 六、风险提示

- **噪声与电磁**：机器人电机与无线通信设备可能对考场环境产生干扰，严禁在考试时段进入考场楼层。
- **成本效益**：建议先在 1-2 个大型考点试点，评估实际替代的人工工时后再规模化采购。
- **安全责任**：需明确机器人与考生发生接触时的责任界定与应急预案，机器人应具备遇人即停策略。
