# 巡考机器人 · 用户需求关键词总结

## 一、总目标
读桌面文档 → 写移动脚本（Wheeltec 阿克曼车，ROS1 真车）→ 完整巡逻系统

## 二、巡线策略（核心）
| 关键词 | 规则 |
| --- | --- |
| 只看眼前线 | 跟画面下部（车头前）的黑线走，不预判远处 |
| 弯到脚下才转 | 弯折点进到车前 30cm 才满舵 |
| 不提前转 | 80cm~1m 处前面还是直线，不许提前打方向 |
| 打满要前进 | 满舵时同时往前走（走圆弧），不是原地磨 |
| 线只是引导 | 脱线没关系，往这个方向走就行 |
| 丢线先顺弯 | 顺弯找 1.8s → 后退 → 前进 → 循环 |
| 能过的弯别退 | 弯道能过就一直转过去 |
| 别一直退 | 后退有预算，不能一看到线就重置 |
| 不要自己停 | 没叫停就不许自己结束 |
| 自我优化 | 过弯成功就记住参数，以后同类弯照那样走 |

## 三、底盘硬约束（实测）
- 原地打方向无效（v=0 舵机不响应，δ=atan(L·w/v)）
- 低速死区 ≈0.12 m/s，低于此完全不动
- 最小转弯半径 ≈1.0 m，偏航率 0.06~0.10 rad/s
- 前轮转向、后轮驱动；+w = 左转
- 电池 <24V 扭矩不足，满舵打不出来

## 四、网页能力
一键跟随黑绳 / 参数面板 / 在线改代码 / 三路画面 / 拍照 / 急停 / 遥测 / 一键启动控制台

## 五、现场校准
IMU 零位、相机俯角（地面占 76%）、距离标定（底行 0.25m）、黑线阈值 V<75、线要 2~3cm 宽
