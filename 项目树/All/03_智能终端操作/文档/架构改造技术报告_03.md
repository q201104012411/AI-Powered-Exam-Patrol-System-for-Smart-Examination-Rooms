## 2. 账号与权限模型

### 2.1 账号存在哪、字段有哪些

**存在 `terminal.db` 的 `kv` 表**，键名 `accounts`（`03/access.py:90-92`）：`AccountStore.KEY = "accounts"`。值是一个 JSON 对象：

```python

data[username] = {"pwd": hash_pwd(password), "role": role,
```

## 4. 现有网络通信能力

### 4.1 结论先说

**没有任何 socket / UDP / TCP / 组播的原始收发代码。** 全模块扫描 `socket.`、`AF_INET`、`SOCK_DGRAM`、`SOCK_STREAM`、`udp://`、`SO_REUSE` 等模式，命中数 **0**（仅 `03/作弊识别/cheatdetect/videosource.py:159` 把 `rtsp://|rtmp://|udp://` 当**视频流 URL 前缀**识别，不是自己建 socket）。

网络能力只有两类：**HTTP 客户端（urllib）** 与 **一个 HTTP 服务端（http.server）**。

### 4.2 服务端：`lan_service.py`（唯一的监听端口）

```python
# 03/lan_service.py:45
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
# 03/lan_service.py:391

```

1. 新增 `03/_account_bridge.py`（照 `_cmd_bridge.py` 写）：入参 `{"module":"01|02","op":"create|reset|delete|list","args":{…},"by_role":…}`，在子进程里 import `01/accounts.py` 或 `02/web_accounts.py` 并调上表函数，最后一行输出 JSON。
