# 智能终端

> 所属：项目六 · 智能化装备与考生数据保护 ｜ 专题 03

## 一、终端类型与定位

| 终端 | 使用角色 | 核心功能 | 形态建议 |
| --- | --- | --- | --- |
| 巡考客户端 | 考点巡考员 | 告警接收、视频回看、复核判定、处置记录 | 台式/一体机 |
| 监考终端 | 监考员 | 本考场告警提示、一键上报、举手呼叫 | 壁挂一体机 / 桌面小屏 |
| 指挥大屏 | 考点/上级指挥中心 | 多考场轮巡、告警态势、统计分析 | 拼接大屏 + 播控主机 |
| 移动巡考 APP | 巡考员、考务管理 | 移动复核、任务派发、拍照留证 | 国产化平板 / 手机 |
| 手持核验终端 | 入场核验、抽查 | 人脸核验、签到、抽签 | 三防 PAD |
| 考场时钟终端 | 考生、监考员 | 标准时间显示、考试指令播报 | 电子时钟终端 |

## 二、功能要求

1. **告警分级展示**：橙/红两级预警差异化呈现（颜色、声音、置顶、弹窗），红色预警强制确认。
2. **复核操作留痕**：复核结论（成立/不成立/误报）、理由、附件一并留档，误报标记进入算法迭代闭环。
3. **断网可用**：与边缘节点直连，断网时本地缓存告警与处置记录，恢复后自动补传。
4. **权限最小化**：按角色分配视图，监考终端仅显示本考场，且默认脱敏展示。
5. **统一管控**：支持 MDM 统一配置、远程升级、应用白名单、外设管控、丢失远程擦除。

## 三、选型与技术要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | 国产化优先（麒麟 / 统信），支持信创整机 |
| 加解密 | 支持国密算法（SM2/SM3/SM4） |
| 显示 | ≥ 1920×1080，支持多路视频同时解码 |
| 网络 | 千兆有线优先，支持双链路切换 |
| 安全 | 终端准入认证、设备指纹、防拆开关、摄像头物理遮挡 |
| 可靠性 | 连续运行 ≥ 72 小时无故障，支持看门狗自恢复 |
| 交互 | 支持一键复核、快捷键操作，适配考务人员操作习惯 |

## 四、与既有系统的衔接

- 终端仅作为**业务呈现与操作入口**，不落地全量视频，避免数据分散风险。
- 与项目一的边缘 AI 节点、项目四的巡考业务平台通过统一接口对接（告警订阅 + 指令下发）。
- 与项目三的统一身份认证对接，实现单点登录与持续校验。

## 五、验收要点

- 终端与平台/边缘节点联通性测试
- 断网降级与恢复测试（缓存、补传完整性）
- 72 小时稳定性运行记录
- 权限矩阵验证（越权访问测试不通过）
