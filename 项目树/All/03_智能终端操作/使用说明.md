# 使用说明 · 智能终端操作端

> 对应《[智能终端.md](../03_智能终端/智能终端.md)》。
> 本目录是**终端侧软件的真实实现**（可运行、有测试）；硬件选型与 MDM 服务端属采购范围。

## 一、怎么启动

| 想做什么 | 双击 |
| --- | --- |
| 打开终端界面 | **启动终端界面.bat** |
| 一键体检（单元测试 + 端到端自检） | **运行自检与测试.bat** |

命令行方式：

```bat
python terminal_gui.py                 :: 打开界面
python -m unittest discover -s tests -t .   :: 76 项单元测试
python main.py                         :: 55 项自检（用临时数据目录，不污染真实数据）
python main.py --real                  :: 用真实 data 目录自检
```

## 二、登录账户

界面会先出登录页，**不同角色看到的和能做的都不一样**（权限最小化）：

| 账户 | 角色 | 可见范围 | 能做什么 |
| --- | --- | --- | --- |
| Owner | **所有者（最高权限）** | 全部考场 | 复核 / 派发 / 导出 / 手持核验 / **终端账户管理** / 清空本地数据 / 隐藏命令行窗口 |
| admin | **管理员** | 全部考场 | 复核 / 派发 / 导出 / 手持核验（**不能管账户、不能清空数据、不能改隐藏窗口开关**） |
| patrol1 | 巡考员 | 全部考场 | 查看 / **复核** / 上报 / 派发 / 导出 |
| inv01 | 监考员 | **仅 A-01** | 查看 / 一键上报；**不能复核**（避免自己判自己） |
| check1 | 核验员 | — | 手持人脸核验 |

> **口令不在界面显示**：登录页与启动器只列出账户名，口令由系统所有者掌握（首次部署后请立即修改）。
> 以 Owner 登录后，「运行状态与管控」页多出三项：**👥 终端账户**（新建/重置口令/删除）、
> **🗑 清空本地数据**、**☐ 隐藏命令行窗口（下次启动生效）**；管理员与其余角色看不到这三项。

登录后可点右上角 **🔄 切换账号** 换人。

## 三、界面四个页签怎么用

### 1. 告警处置
- 列表按 **红色优先、其次超时、再按时间** 排序；红色底红字、橙色底黄字
- **红色预警**会弹窗提醒，且**必须先点「✓ 确认选中」才能复核**
- 考生编号**默认脱敏**（`3301**********1234`）
- 选中一行，下方会显示该告警的**全过程留痕**（接入 → 确认 → 复核）
- 巡考员/指挥中心可点「🧪 生成演示告警」造一批橙色+红色数据（来源标注 `demo`，不冒充真实接入）
- 右上「☁ 立即补传」把待补传告警推给平台

### 2. 复核留痕
- 填 **告警 ID**（在告警页选一行会自动带入）、**结论**（成立/不成立/误报）、**见证人**、**附件**、**理由**
- **理由必填**——留痕要求，不填提交不了
- 结论选「误报」会自动进入**算法迭代闭环**，可在「误报统计」里按告警码看误报率
- 附件支持 `.png/.jpg/.jpeg/.webp/.txt/.pdf/.mp4`，会拷进 `data\attachments\` 留档

### 3. 手持核验
- 调 **01_人脸识别与身份核对** 做真实人脸核验（子进程隔离调用，不复制算法）
- 选模式（1:1 / 1:N）、填考生编号、选图片 → 开始核验
- 顶部会如实显示桥接状态：01 目录、`verifier.py`、人脸模型三者缺一就会提示缺什么
- **未建档时不会假装成功**，会明确提示"特征索引不可用（需先建档）"

### 4. 运行状态与管控
- 左侧：在线状态、待补传条数、告警统计、**审计链校验**
- 右侧：统一管控配置（白名单/外设）、**稳定性心跳与最长连续时长**、标准时间与下一条播报
- 「写一次稳定性心跳」手动写一条；界面运行时每 30 秒自动写

## 四、断网怎么表现

1. 告警接入后**先落本地**（SQLite `synced=0` + `data\outbox\outbox.ndjson` 备份），本机功能完全不受影响
2. 状态栏显示"离线"，待补传条数照常累加
3. 网络恢复后**自动批量补传**（也可手动点「☁ 立即补传」），成功才置为已同步
4. 超过 72 小时的陈旧记录**不静默丢弃**，标记后写一条「补传超期丢弃」审计

## 五、数据放在哪

| 路径 | 内容 |
| --- | --- |
| `data\terminal.db` | 告警、复核留痕、审计链、管控指令、终端账户 |
| `data\attachments\` | 复核附件 |
| `data\outbox\outbox.ndjson` | 断网队列的 NDJSON 副本（便于人工核对） |
| `data\logs\soak.log` | 72 小时稳定性心跳记录 |
| `data\logs\gui_crash.log` | 界面崩溃时的堆栈 |

换位置：设环境变量 `EXAM_TERMINAL_HOME`，或在本目录写 `terminal_home.txt`。

## 六、接平台/边缘节点

设好环境变量即可，未配置时界面会**如实显示"未配置"**，不会假装联通：

```bat
set EXAM_PLATFORM_URL=http://10.0.0.10:8080
set EXAM_EDGE_URL=http://10.0.0.11:9000
set EXAM_AUTH_URL=http://10.0.0.12:7000
set EXAM_FACE_MODULE_DIR=D:\...\01_人脸识别与身份核对\01_人脸识别与身份核对
```

平台侧需实现的接口见 `README.md` 第四节。平台下发的指令（`set_config` / `peripheral` /
`wipe` / `upgrade` / `report`）由 `fleet.apply_pending()` 逐条生效。

## 七、注意事项

1. **远程擦除需二次确认**：`execute_wipe()` 必须传确认码 `WIPE` 才执行；执行时如果数据库正被占用，
   会**如实报告哪一项没删掉**，不会谎报成功。
2. **升级只登记不刷机**：`upgrade` 指令只记录任务与校验信息，实际刷机不在本模块。
3. **稳定性未满 72 小时就是"未达标"**：`soak_status()` 按心跳间隔判定连续性，缺口会断掉连续时长。
   这项验收**必须靠真实运行积累**，代码只能帮取证。
4. **脱敏是默认行为**：导出也走脱敏口径（`access.export_payload`）。
5. **审计链**：所有接入/确认/复核/管控动作都进 `sha256(prev + 规范化JSON)` 哈希链，
   可在界面点「校验审计链」验证是否被篡改。
6. **本目录不做视频解码**，也不落地全量视频——符合《智能终端.md》第四节"终端不落地全量视频"的约束。
