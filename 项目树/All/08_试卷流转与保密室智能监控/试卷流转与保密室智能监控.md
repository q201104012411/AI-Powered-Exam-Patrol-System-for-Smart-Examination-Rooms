# 试卷流转与保密室智能监控（自主补充）

> 所属：项目六 · 智能化装备与考生数据保护 ｜ 专题 08
> 补充理由：试卷安全是考试安全的"最高优先级"，且属非考试时段场景，正好由本项目的机器人、终端与视频能力复用覆盖。

## 一、保密室智能监控

| 监控项 | 技术手段 |
| --- | --- |
| 无死角视频 | 保密室 6 面覆盖（含柜顶/柜底），双路冗余录像 |
| 门禁管控 | 人脸 + 刷卡/密码双因子，双人双锁电子化 |
| 入侵探测 | 红外双鉴、门窗磁、震动/开柜检测 |
| 试卷柜电子锁 | 电子锁 + 开柜记录 + 柜内状态监测 |
| 环境监测 | 温湿度、水浸、烟感，异常自动告警 |
| 值守替代 | 巡考机器人定时巡查 + 非接触值守（见专题 04） |
| 录像留存 | 按当地考务规定留存（建议 ≥ 6 个月），期间不可删改 |

## 二、试卷流转环节

| 环节 | 措施 |
| --- | --- |
| 领取/交接 | 扫码/RFID 电子交接，双人签字 + 人脸确认 |
| 押运 | 车辆北斗/GPS 定位 + 车内视频回传 + 路线偏离告警 |
| 电子铅封 | 试卷袋电子封签，异常开启即时告警 |
| 分发至考场 | 分发记录与考场、时间、责任人一一对应 |
| 回收与封存 | 回收扫码核验数量，异常差异即时上报 |

## 三、关键指标

| 指标项 | 要求 |
| --- | --- |
| 保密室视频覆盖率 | 100%，无盲区（逐机位留档验证） |
| 开柜/开门异常告警时延 | ≤ 5 秒 |
| 交接记录完整率 | 100% 可追溯（人、时、物、地点） |
| 录像留存与完整性 | 留存期内连续可回放，无丢段 |
| 押运路线偏离告警 | 偏离即报，≤ 30 秒 |

## 四、验收证据

- 保密室无死角核查报告（含机位图与实拍画面）
- 门禁与开柜告警联调测试记录
- 交接/押运流程演练记录与台账样例
- 录像完整性与留存期限配置证明
