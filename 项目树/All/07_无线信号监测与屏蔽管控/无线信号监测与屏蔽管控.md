# 无线信号监测与屏蔽管控（自主补充）

> 所属：项目六 · 智能化装备与考生数据保护 ｜ 专题 07
> 补充理由：无线作弊器材（隐形耳机、数传设备）是 AI 视频与音频难以完全覆盖的盲区，需要频谱手段补齐。

## 一、建设内容

| 模块 | 功能 |
| --- | --- |
| 频谱监测 | 考场及周边频段扫描，发现异常/持续发射信号 |
| 信号定位 | 多站测向或手持侦测，逐步逼近定位发射源 |
| 作弊信号特征库 | 积累常见作弊数传信号特征，支持自动匹配告警 |
| 屏蔽管控 | 按考场定向屏蔽 4G/5G/WiFi/蓝牙等频段 |
| 统一管控 | 屏蔽设备开关、功率、时段集中管理，考试结束自动关闭 |

## 二、关键技术要求

| 项目 | 要求 |
| --- | --- |
| 屏蔽频段 | 覆盖 2G/3G/4G/5G、WiFi 2.4G/5.8G、蓝牙、常见对讲频段 |
| 屏蔽范围 | 定向可控，覆盖考场不漏、不过度外溢 |
| 合规保障 | **不得干扰合法公众通信**，须依法履行报备/审批手续 |
| 计时管控 | 与考试时间表联动，开考前开启、结束即关 |
| 监测覆盖 | 考点全域 + 周边 100 米可疑区域 |
| 告警时延 | 异常信号发现 ≤ 10 秒 |

## 三、合规红线（重要）

1. **必须依法报备**：无线电屏蔽设备的使用须取得无线电管理机构批准，不得擅自设台。
2. **功率与方向控制**：以定向、低功率、贴近考场的方式实现覆盖，避免影响周边居民合法通信。
3. **时间严格限定**：仅考试时段开启，结束后立即关闭并留存开关记录。
4. **与运营商协同**：提前告知运营商并取得配合，必要时由其协助优化。

## 四、验收证据

- 屏蔽效果实测（考场内各频段实测场强、屏蔽有效率）
- 外溢测试（考点外围合法通信可用性验证）
- 审批/报备文件
- 开关时段记录与考试时间表一致性核对
