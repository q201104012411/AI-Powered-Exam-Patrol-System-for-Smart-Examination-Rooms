# 07 无线信号监测与屏蔽管控（可运行实现）

> 项目六 · 智能化装备与考生数据保护 ｜ 专题 07
> 频谱发现无线作弊（隐形耳机/数传/图传）＋ 按考试时间表统一管控屏蔽设备 ＋ 合规留痕与验收。

## 快速入口

| 想做什么 | 双击/命令 |
| --- | --- |
| 先看完整效果（不碰真实数据） | `一键演示.bat --sandbox` |
| 打开界面（8 页签） | `启动.bat` |
| 跑自检（375 项） | `运行自检.bat` |
| 接真频谱仪/监测站 | `启动采集服务.bat`（HTTP `POST /api/scan`） |
| 命令行调用 | `python integration_api.py --op status --args "{}"` |
| 检查是否写脏其它模块 | `python 工具_检查其它模块是否被污染.py` |

## 能力一览

- **频谱监测**：噪声底/峰值/占空推断、作弊特征库（14 条，可解释打分）、异常分级、
  自身屏蔽信号剔除、同频合并、发现时延统计
- **信号定位**：多站场强最小二乘、多站测向交会、单站径向、手持侦测逼近提示
- **屏蔽管控**：开机闸门（审批/窗口/定向/功率/在线）、时间表自动开关、开关记录、
  外溢估算与实测、屏蔽效果实测
- **合规验收**：18 项红线/技术/证据体检、开关记录与时间表一致性核对、验收报告 md+csv
- **跨模块联动**（只调用，不改其它模块）：07→03 告警、06→07 安检关联、02 机位参考、
  00 集成联动总线、跨机局域网接入服务（03 `lan_service.py`）

## 边界（如实说明）

本机没有频谱仪/屏蔽器实物：频谱检测、定位、屏蔽状态机、时间表联动、体检、报告都是
真实业务逻辑；模拟数据标 `source=sim`，屏蔽"开启"不真的发射射频，接上真设备后由
`ingest_service.py` 与屏蔽指令适配层对接。外溢/屏蔽效果以现场实测为验收依据，估算值不作结论。
