# 4.2 运维方案

> 所属项目：项目四 · 验收与运维

## 一、质保期

- 建议**不少于 3 年**
- 质保期内**免费提供系统升级和算法优化服务**

## 二、响应时效

| 故障级别 | 响应要求 |
| --- | --- |
| 系统故障 | **2 小时内**远程响应 |
| 重大故障 | **4 小时内**到场处理 |

## 三、巡检制度

| 时间节点 | 巡检内容 |
| --- | --- |
| 每学期开学前 | 完成一次全面巡检 |
| 考试前一周 | 完成专项检查 |

## 四、算法迭代

- 建立**误报反馈闭环**：复核人员标记的误报数据用于模型迭代优化
- 建议**每学期更新一次**算法模型

## 五、运维职责分工（建议）

| 角色 | 职责 |
| --- | --- |
| 供应商运维团队 | 远程监控、版本升级、算法迭代、重大故障到场 |
| 考点信息管理员 | 日常设备状态检查、链路确认、告警上报 |
| 考务管理人员 | 复核流程执行、培训组织、演练组织 |
