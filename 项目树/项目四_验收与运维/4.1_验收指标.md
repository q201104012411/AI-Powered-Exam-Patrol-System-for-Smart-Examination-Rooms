# 4.1 验收指标

> 所属项目：项目四 · 验收与运维

## 一、验收指标表

| 指标项 | 验收标准 | 检测方式 |
| --- | --- | --- |
| 人脸识别误识率 | ≤ 0.1% | 第三方检测报告（CNAS/CMA） |
| 人脸识别拒识率 | ≤ 1% | 同上 |
| 行为识别准确率 | ≥ 95% | 实际考试场景测试 |
| 告警响应时间 | ≤ 3 秒 | 系统日志分析 |
| 系统可用性 | ≥ 99% | 试运行期间统计 |
| 人脸比对速度 | 1:1 比对 ≤ 1 秒，1:N ≤ 3 秒 | 性能测试 |

## 二、第三方检测要求

- 人脸识别**误识率和拒识率**须提供权威合法检测机构报告作为验证依据
- 供应商应提供有 **CMA 和 CNAS 标志**的第三方检测报告

## 三、验收资料清单

| 序号 | 资料名称 | 提供方 |
| --- | --- | --- |
| 1 | 第三方检测报告（CNAS/CMA） | 供应商 |
| 2 | 试点报告与算法准确率数据 | 实施方 |
| 3 | 试运行记录与系统可用性统计 | 实施方 |
| 4 | 培训记录与操作手册 | 实施方 |
| 5 | 全流程模拟演练报告 | 考点 / 实施方 |
| 6 | 运维方案与应急预案 | 供应商 |
| 7 | 合规材料（告知同意模板、数据保留与销毁策略、审计日志样例） | 供应商 |
| 8 | 个人信息保护影响评估（DPIA）报告、数据出境风险评估结论 | 供应商 / 考试机构 |
| 9 | 数据销毁审计报告 | 供应商 / 数据安全责任人 |

## 四、指标口径与验收属性（口径统一，与项目书 2.4 / 附录 B 一致）

| 指标 | 口径 | 属性 |
| --- | --- | --- |
| 行为识别精确率（=1−误报率） | 复核成立告警 ÷ 告警总数 | **否决项**（<95% 即验收不通过） |
| 疑似行为识别提示率 | 正确提示 ÷ 实际异常（召回率） | 能力观测项，不作验收条件 |
| 误报率相对下降幅度 | (优化前−优化后) ÷ 优化前 | 过程改善指标，非验收标准 |
| 告警响应时间 / 摄像机在线率 / 考场覆盖完整性 / 加密率 / 审计覆盖率 | 见项目书附录 B | **否决项** |
| 人脸识别拒识率 / 系统可用性 / 比对速度 / 大教室去重准确率 | 见项目书附录 B | 允许整改后复验（≤2 次，15 个工作日内） |

> 说明：全文指标以**项目书附录 B《核心指标汇总表》**为唯一权威口径；本表与附录 B 冲突时以附录 B 为准。
